# Cami — knockout (death)

Integrada como death: se usa en knockout y derribos. 30 FPS sin bucle, duración aproximada 1.37 s para completar la caída antes del tiempo actual de reaparición (1.4 s). Al terminar mantiene el cuadro final en el suelo. Hereda el tamaño y pivote de Cami. Preview 2× nearest con pausa final de 0.2 s.
