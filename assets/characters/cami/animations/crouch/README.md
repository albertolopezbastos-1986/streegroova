# Agacharse — cami

Carpeta para la hoja crouch.png, con alfa transparente y los pies alineados. Cuando se agregue la hoja, registrar su cuadrícula, tamaño, pivote y cuadros en character.json. La hoja activa actual de Beto está en assets/characters/beto/animations/crouch/; no se duplica como una falsa variante de 20 o 40 cuadros.
