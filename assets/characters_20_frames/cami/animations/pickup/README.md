# Recoger objetos — cami

Carpeta preparada para pickup.png: agacharse, bajar la mano al suelo, agarrar y levantarse. Se activa con golpe cerca de comida o de un arma; no usa una tecla de agachado independiente.

Agregar la hoja con transparencia y pies alineados. Registrar sus medidas reales, cuadrícula, cuadros, FPS y collect_progress en character.json al integrar los sprites. La animación activa de referencia de Beto está en assets/characters/beto/animations/pickup/. Esta carpeta no contiene sprites propios todavía.
